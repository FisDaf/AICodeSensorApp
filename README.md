# AICodeSensor - Детектор уязвимостей в коде

Приложение для анализа Python-кода с использованием нейронной сети CodeBERT.

## Первичная настройка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск приложения

```bash
python run.py
```

### Функции

1. **Загрузка файлов** - нажмите "Загрузить файлы" для выбора Python файлов
2. **Анализ на наличие плагиата** - файл после загрузки автоматически выдаёт результат тестирования

## Требования

- Python 3.8+
- PyTorch (с CUDA поддержкой или CPU)

## Примечания

- Первый запуск может быть медленным (загрузка моделей)
- GPU ускорит анализ больших файлов в 5-10 раз
