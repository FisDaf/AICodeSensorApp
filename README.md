# AICodeSensor

AICodeSensor — приложение для анализа исходного кода и выявления подозрительных фрагментов с помощью модели CodeBERT.

## Что делает проект

- Загружает и анализирует файлы Python и C/C++
- Оценивает каждый токен на вероятность «подозрительности»
- Подсвечивает проблемные участки в результирующем HTML-отчёте
- Показывает статус файла: безопасно / подозрительно / опасно

## Ключевые особенности

- Графический интерфейс на PySide6
- Использование CodeBERT + собственный классификатор
- Скользящее окно для анализа больших файлов
- Оценка на уровне токенов и автоматическое сглаживание
- Поддержка анализа нескольких файлов за один запуск

## Структура проекта

- `run.py` — главный запуск приложения
- `MainWindow.py` — GUI и логика загрузки файлов
- `CodeSensor.py` — анализ текста и подсчёт подозрительной плотности
- `CodeBertDetector.py` — модель CodeBERT с кастомным классификатором
- `HtmlVisualizer.py` — генерация цветного HTML-отчёта
- `requirements.txt` — список зависимостей
- `weights/` — заранее обученные веса моделей
- `test.ipynb` — пример анализа и исследования модели

## Установка

1. Убедитесь, что у вас установлен Python 3.8 или новее
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Убедитесь, что скачаны файлы моделей:

- `weights/py_v2.pth`
- `weights/cpp_old.pth`

## Запуск

Запустите приложение из каталога `AICodeSensorApp`:

```bash
python run.py
```

Если на машине есть GPU с CUDA, приложение автоматически выберет его. В противном случае будет использоваться CPU.

## Как пользоваться

1. Нажмите кнопку «Загрузить файлы»
2. Выберите один или несколько файлов `.py`, `.cpp`, `.h` и т.д.
3. Нажмите файл в списке, чтобы увидеть HTML-отчёт
4. Подозрительные участки выделяются цветом

## Поддерживаемые форматы

- Python: `.py`
- C/C++: `.cpp`, `.c`, `.h`, `.hpp` (через общий путь обработки токенов)

## Что означают статусы

- `✓ Файл безопасен` — минорное количество подозрительных токенов
- `? Подозрительно` — часть кода содержит отклонения от нормы
- `⚠ Опасно` — высокий уровень подозрительных токенов

## Тестирование и исследование

- `test.ipynb` содержит примеры использования и визуализацию работы модели
- В каталоге `tests/` находятся примеры файлов для анализа
- `static/` содержит ресурсы интерфейса, включая иконки

### Как запустить `test.ipynb`

1. Установите Jupyter Notebook или JupyterLab, если ещё не установлен:

```bash
pip install notebook
```

2. Откройте `test.ipynb` из каталога `AICodeSensorApp`:

```bash
jupyter notebook test.ipynb
```

или

```bash
jupyter lab test.ipynb
```

3. Запустите ячейки по порядку, чтобы увидеть примеры анализа и результаты визуализации.

4. При необходимости используйте файлы из `tests/` для проверки других сценариев.

## Дополнительные заметки

- Первый запуск может быть медленным из-за загрузки модели CodeBERT
- GPU значительно ускоряет анализ больших файлов
- Если модель не найдена, проверьте путь `weights/` и наличие файлов
