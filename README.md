# AICodeSensor - Детектор уязвимостей в коде

Приложение для анализа Python-кода с использованием нейронной сети CodeBERT.

## Структура проекта

```
├── mainwindow.py          # Главное окно приложения (PySide6)
├── model.py               # Анализаторы кода и функции детектирования
├── model_loader.py        # Загрузка и инициализация моделей
├── setup.py               # Скрипт инициализации и проверки зависимостей
├── requirements.txt       # Зависимости Python
├── detector_v2_ep10.pth   # Обученная модель (размер ~200 МБ)
└── form.ui                # UI дизайн (Qt)
```

## Первичная настройка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Инициализация проекта

**Запустите перед первым использованием:**

```bash
python setup.py
```

Этот скрипт проверяет:
- ✓ Наличие всех Python пакетов
- ✓ Загрузку CodeBERT токенайзера
- ✓ Наличие файла модели (`detector_v2_ep10.pth`)
- ✓ Доступность GPU/CPU

## Использование

### Запуск приложения

```bash
python mainwindow.py
```

### Функции

1. **Загрузка файлов** - нажмите "Загрузить файлы" для выбора Python файлов
2. **Первичный анализ** - автоматически выделяет подозрительные файлы красным
3. **Базовый анализ** - клик на файл показывает код с подсветкой синтаксиса

## Архитектура

### model_loader.py
Отвечает за:
- Загрузку предобученной модели CodeBERT
- Инициализацию токенайзера
- Определение вычислительного устройства (GPU/CPU)

### model.py
Содержит:
- `CodeSensorModel` - простая подсветка синтаксиса
- `predict_long_code()` - предсказание по скользящему окну
- `visualize_long_ai_code()` - визуализация с цветовыми кодами

### mainwindow.py
GUI приложение на PySide6 с:
- Списком загруженных файлов
- Областью просмотра результатов анализа
- Кнопками загрузки и визуализации

## Требования

- Python 3.8+
- PyTorch (с CUDA поддержкой или CPU)
- Transformers
- PySide6
- файл `detector_v2_ep10.pth` (обученная модель)

## Примечания

- Первый запуск может быть медленным (загрузка моделей)
- GPU ускорит анализ больших файлов в 5-10 раз
- Модель оптимизирована для Python кода
